# Student Management System (C)

A console application in C for managing student records stored in a text file.

![C](https://img.shields.io/badge/C-A8B9CC?logo=c&logoColor=black)

## Features

- Add, find, edit and delete a student
- List all students
- Persistent storage in `students.txt`

Each record holds a student number, first name, last name, department and year, stored in a `struct`.

## Build and run

Open `odevc.sln` in Visual Studio and run, or compile with MSVC:

```bash
cl odevc\MarimMahmoud_22670310118_Odev.c
```

The code uses `scanf_s`, so it targets the Microsoft C compiler.
